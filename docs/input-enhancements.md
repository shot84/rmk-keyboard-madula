元の5レイヤー、既存キー割り当て、スクロール方向、保存領域とスキーマID、Rynk v0.2対応を維持しています。

## IQSの操作

1本指はカーソル、2本指はスクロール、1/2/3本指タップは左/右/中クリックです。
指なしが30ms続くまでタッチを終了しません。既定ではカーソルを等倍、フィルタbetaを40、
指離れ対策を3フレーム（約33ms）にしています。指離れ対策は末尾の動きを捨てる代わりに遅延を加えます。
1本指タップ後150ms以内に再度触れると左ボタンを保持してドラッグします。

3本指は既定でスワイプです。仮想位置 `(4,10)`〜`(4,13)` が順に上・下・左・右です。
既定の割り当てはすべて `No` です。Vial/Rynkで使用するOSに合わせて割り当ててください。
Vialでは下段に追加した4キーを編集します。調整キーは空いているキーへ割り当てて使用します。

| User番号 | 動作 |
| --- | --- |
| 18 | 3本指スワイプ/ドラッグ切替 |
| 19 | フィルタbeta 80/40/20/10 |
| 23 / 24 | カーソル速度を下げる/上げる（1/4〜2倍） |
| 25 / 26 | スクロール速度を下げる/上げる |
| 27 / 28 | タップ判定時間を短く/長く（150〜400ms） |
| 29 | 調整値を初期値へ戻す |
| 30 | タップドラッグON/OFF |
| 31 | 指離れ対策OFF/3/5フレーム |

VialではUserタブのPad名、Rynkでは対応するUser番号を使用します。
20〜22は既存のDial操作です。調整値はRAMのみで、再起動すると既定値へ戻ります。
LEDの橙点滅で設定段階を表示します。これらの調整はIQS版だけで有効です。

## 取り込み時の修正・検証

- 指離れ対策の深さを変更したら保持バッファをクリアし、古い移動の再出力を防止。
- フィルタのI2C書き込み成功時だけ適用済み値を更新し、失敗時は次サンプルで再試行。
- 指離れバッファの最大深さでも範囲外アクセスしないよう修正。
- 設定整合性・IQSジェスチャーと回帰テストを実施。ファームウェア各種のCIビルドで確認。
- この統合版の実機USB/BLE操作・再接続・保存の検証は未実施。
